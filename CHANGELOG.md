# Changelog

All notable changes to `form-handler-kyc` will be documented in this file.

## v1.1.0 - 2026-07-31

### Added
- Shared Form Flow screen and action components for KYC initiation and status pages
- Configurable default, compact, and immersive UI variants
- Laravel 12/13 and Inertia 2/3 compatibility matrix

### Changed
- Require Form Flow 1.8 or newer
- Support both HyperVerge 1.1 and the HyperVerge 2.0 beta line
- Align callback integration tests with the cached cross-session context contract

## v1.0.0 - 2024-12-24

### Added
- Initial release
- HyperVerge KYC integration
- External redirect to mobile app
- Callback handling and status polling
- Contact-level KYC persistence
- Auto-registration with Form Flow Manager
- Automated install command
